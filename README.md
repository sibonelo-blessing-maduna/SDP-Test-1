# Repo Analysis Tool (RAT) — COMS3011A Test

A web-app dashboard that measures repository metrics (churn, growth, ownership, and
more) per author, per file, per directory, and per repository — for multiple
repositories, with filtering by time period or manually selected commits.

## Status

🚧 Under construction.

| Path | Purpose |
| --- | --- |
| `test_brief.pdf` | Provided test brief (COMS3011A, Wits) |

| `backend/` | FastAPI app: git ingestion + metric engine + REST API |
| `frontend/` | Vite + React dashboard |
